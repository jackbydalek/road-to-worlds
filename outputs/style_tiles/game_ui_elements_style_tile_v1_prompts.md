# Game UI Elements Style Tile v1 — Generation Prompts

## Initial generation

Use case: ui-mockup

Asset type: production UI visual-identity style tile for the original game “Kitchen Table: Road to Worlds”

Primary request: Create one polished landscape 16:9 UI style tile that defines the complete interface language for a game combining a bright modern low-poly card-shop overworld with cozy hand-illustrated physical cards. The UI should feel like contemporary local-game-store signage, matte retail fixtures, acrylic card stands, printed event flyers, and premium card sleeves—not like a generic dark developer dashboard or an old fantasy scrapbook.

Design concept: “modern hobby shop meets handmade TCG.” Use clean confident geometry, friendly condensed display typography, tactile cream paper content surfaces, matte teal navigation surfaces, cocoa-ink outlines, selective orange action accents, shallow offset shadows, subtle paper grain, and very restrained low-poly bevels. The UI must be bright, readable, playful and shippable.

Composition/framing: one organized style tile with clearly separated modules: (1) typography and core palette; (2) full button state family; (3) tabs and navigation; (4) panels, modal, tooltip, toast and contextual hint; (5) compact overworld HUD; (6) card-combat HUD; (7) icon and affinity system; (8) four background treatments; (9) motion/interaction cues represented with short arrows and state frames. Strong hierarchy, generous spacing, no dense paragraphs.

Buttons: show PRIMARY, SECONDARY, SELECTED, HOVER, PRESSED, DISABLED and DANGER. Primary button is matte teal with cream type and a small orange lower-edge accent; secondary is cream with cocoa outline; selected looks like a stamped event-ticket or active store-sign tab; hover lifts slightly with warm rim; pressed compresses shadow; disabled is low-contrast but still readable; danger uses restrained red-orange. Use 8–10 px rounded corners, 2 px cocoa outline, compact proportions, no pill overload.

Panels: cream paper information panel with subtle fiber grain; matte teal navigation header; translucent dark cocoa gameplay overlay used sparingly; clear acrylic-style card inspection panel with light refraction but no glassmorphism excess; modal that resembles a clean tournament registration card; tooltip like a clipped price tag; toast like a small printed receipt; bottom contextual prompt narrow and unobtrusive.

HUD samples: overworld HUD with “WEEK 3 • SATURDAY”, “$42”, deck/calendar/settings icons and a small “Talk” interaction prompt; combat HUD with “TURN 5”, Chef life badges, physical-looking “END TURN” control, narrow instruction strip, card focus and legal-target state. Keep HUD attached to edges or physical objects, not giant floating dashboards.

Tabs/navigation: binder-divider tabs and modern store wayfinding signs. Show “SHOP”, “DECK”, “EVENTS”, “META”, “SETTINGS”; active tab uses teal fill plus orange notch; inactive tabs remain cream and quiet.

Icon system: original chunky monoline icons with slightly irregular hand-inked terminals for deck, calendar, wallet, settings, save, trade, booster and tournament. Five matching affinity icons: chili flame, steaming bowl, wrapped candy, lime leaf, pickle sparkle. Icons must not look like operating-system emoji.

Background treatments: (A) bright low-poly shop scene with soft edge vignette for HUD; (B) warm cream paper menu background with faint card-shop floor-plan watermark; (C) teal felt tabletop texture for combat; (D) darkened blurred shop overlay for modals, still preserving environmental color. Backgrounds should support content without becoming empty flat black.

Typography: bold friendly condensed display lettering for headings and numbers, paired with an extremely readable humanist sans-serif for rules and UI. Show headline, body, small label and numeric styles.

Color palette: parchment cream #F7E9C8, cocoa ink #241B17, warm white #FFF9ED, light oak #C99B63, muted teal #2D6F6A, deep teal #1D4E4B, action orange #E96A35; affinity accents Spicy #E94E2F, Hearty #56A044, Sweet #36A3E6, Fresh #F4C542, Funky #9138A6. Maintain accessible contrast.

Materials/textures: fine paper grain, matte laminate, teal felt, light oak edge, acrylic display plastic, printed ink and subtle screen-print misregistration. Use texture lightly; never compromise legibility.

Text: “UI SYSTEM”, “TYPOGRAPHY”, “BUTTONS”, “PRIMARY”, “SECONDARY”, “SELECTED”, “HOVER”, “PRESSED”, “DISABLED”, “DANGER”, “PANELS”, “HUD”, “ICONS”, “BACKGROUNDS”, “SHOP”, “DECK”, “EVENTS”, “META”, “SETTINGS”, “WEEK 3 • SATURDAY”, “$42”, “Talk”, “TURN 5”, “END TURN”, “Choose a card.”

Constraints: practical production UI reference, cohesive with the established bright modern low-poly shop and cozy illustrated cards, high contrast, original branding, clear state differentiation, contemporary but warm. Avoid generic navy dashboard UI, neon sci-fi, medieval parchment scrolls, excessive skeuomorphism, glossy mobile-game gradients, tiny text, huge opaque panels, colored emoji, copyrighted game UI, extra slogans, watermarks and dense prose.

## Bright-shop correction

Use case: precise-object-edit

Asset type: corrected final UI style tile for “Kitchen Table: Road to Worlds”

Primary edit: Change only the small environment imagery inside “HUD – OVERWORLD” and “BACKGROUNDS” samples A and D so they depict the established bright modern low-poly card shop rather than a dark rustic wood-dominated store.

Modern shop correction: pale cream walls, large glass storefront daylight, high-key exposure, light terrazzo floor, light-oak shelving, matte teal counters, white ceiling, clean black track lights, clear acrylic displays, colorful organized products, modern tournament tables, bright community atmosphere. Background D may remain intentionally blurred/dimmed for a modal, but its underlying store must still visibly be this bright contemporary shop.

Preserve exactly: the entire style-tile grid and composition; all headings and labels; typography samples; palette; every button and state; tabs and navigation; panels; modal; tooltip; toast; contextual hint; combat HUD; icons; affinity symbols; background B paper treatment; background C felt treatment; motion and interaction cues; all spacing, borders, shadows, colors and overall rendering style.

Constraints: edit only those specified shop-image regions; do not redesign or move other modules; keep text readable; no dark rustic tavern, bakery, fantasy shop, photorealism, neon sci-fi, extra text, logos, or watermark.

# Season Loop

## Starting a Run

Choose one of three Kitchen starters:

- **Spicy** — pressure, direct damage, and aggressive Plated units
- **Hearty** — durable units, healing, and resilient Meals
- **Sweet** — draw, disruption, and Prep-based support

Then choose a border:

- **White** — standard rules
- **Blue** — stronger opponents and earlier deck upgrades
- **Yellow** — reduced starting money
- **Silver** — only one season life
- **Gold** — the opening chef can change between tournament rounds

## Calendar

The season advances through Weekly Locals, Monthly Regionals, State Championship, Nationals, and Worlds. Only the next uncleared event is selectable. Each event defines its rounds, required wins, entry fee, rewards, and final rival.

Missing the required record costs one season life. If lives remain, the same event stays selected for another attempt. Winning the required record unlocks the next event. Clearing Worlds ends the run as season champion.

## Preparation

Between events:

- Buy exact cards from the singles case.
- Buy a six-card booster.
- Open earned prize packs.
- Add owned cards to the 30-card main deck or sideboard.
- Sell copies beyond the safe deck limit.
- Read metagame reports before choosing changes.
- Work a shop shift if the legal deck is ready but the entry fee is short.

Deck legality requires exactly 30 main-deck cards, no more than six sideboard cards, legal copy counts, and enough owned copies.

## Tournament Rounds

Season tournaments launch a live Kitchen Table match each round. The run's deck becomes the player match deck. The event generates a rival archetype and deck; later events and Blue difficulty improve opposing lists.

Finishing or forfeiting the match produces a tournament result. After every scheduled round, the event evaluates the record, pays rewards, updates the metagame, and either advances the calendar or removes a season life.

Debug tournaments use the same deck quality, opponent, matchup, record, economy, and reward systems but may resolve quickly without playing each match.

# Roboto font source

- Family: Roboto
- Source: https://fonts.google.com/specimen/Roboto
- Upstream file: https://github.com/google/fonts/blob/main/ofl/roboto/Roboto%5Bwdth%2Cwght%5D.ttf
- License: SIL Open Font License 1.1 (`OFL-Roboto.txt`)

`Roboto.ttf` is the variable TrueType font distributed by the Google Fonts
project. Card text uses its default regular face; card titles retain the
existing programmatic emboldening.

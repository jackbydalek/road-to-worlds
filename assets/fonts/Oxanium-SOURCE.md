# Oxanium

- Typeface: Oxanium variable upright
- Designer: Severin Meyer
- Source: https://github.com/google/fonts/tree/main/ofl/oxanium
- Original project: https://github.com/sevmeyer/oxanium
- Bundled font: `Oxanium-SemiBold.ttf` (weight 600)
- License: SIL Open Font License 1.1; see `OFL-Oxanium.txt`

The game uses this face for display titles, section headings, counters, and
short interface labels. Atkinson Hyperlegible Next remains the readable face
for rules, instructions, tooltips, and longer copy.

# Material Symbols Sharp subset

These SVGs are an intentionally small subset of Google's Material Symbols
Sharp collection, downloaded from the official
[`google/material-design-icons`](https://github.com/google/material-design-icons)
repository on 2026-08-26.

The files use the default unfilled 24 px Sharp variants. Their root fill is
normalized to white so Godot can tint them for dark, light, selected,
disabled, and semantic button states. They are licensed under the Apache
License 2.0; see `LICENSE.txt` in this directory.

TOP CUT uses these for familiar interface actions only. Affinity marks, route
nodes, card classifications, and character symbols remain project-authored.

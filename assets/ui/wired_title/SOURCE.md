# Sketch UI support textures

These project-owned SVG textures support the remaining paper panels, singles
tiles, and Draft Night star in the native Godot UI. Button textures from the old
prototype were removed after buttons moved to the shared angular runtime style.

The original rough-line treatment was informed by
[Wired Elements](https://github.com/rough-stuff/wired-elements), but the project
does not embed Wired Elements, RoughJS, Lit, or any third-party runtime code.
Wired Elements is MIT-licensed and credits Preet Shihn.

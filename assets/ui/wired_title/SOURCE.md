# Wired title-screen prototype

These project-owned SVG textures were created for the native Godot sketch UI
prototype. They use irregular double outlines inspired by the visual language of
[Wired Elements](https://github.com/rough-stuff/wired-elements), but do not embed
Wired Elements, RoughJS, Lit, or any third-party runtime code.

Wired Elements is MIT-licensed and credits Preet Shihn.
